# KLAB 홈페이지 데모 (팀 설명용 예시)

실제 서비스가 아니라, "폴더 구조 → 웹페이지" 개념을 팀원들에게 설명하기 위한
아주 간단한 정적 HTML 데모입니다. 빌드 과정 없이 `index.html`을 브라우저로 열면 바로 확인할 수 있습니다.

## 실행 방법

- `index.html`을 더블클릭해서 브라우저로 열면 됩니다. (별도 설치/서버 불필요)
- 또는 VSCode의 Live Server 확장을 쓰면 더 편합니다.

## 페이지 구성

| 페이지 | 설명 |
|---|---|
| `index.html` | 홈 — 업무소개/최신정보 요약 미리보기 |
| `services.html` | 업무소개 — 연구개발팀/연구평가팀 서비스 전체 |
| `news.html` | 최신정보 — 신기술/트렌드/해외출장 등 기사 목록 (카테고리 필터 포함) |

## 폴더 구조 ↔ 웹페이지 매핑 개념

지금 프로젝트 폴더 구조가 곧 웹사이트의 정보 구조(IA, Information Architecture)가 됩니다.

```
KLAB 홈페이지 제작/
├─ 연구개발팀/                              →  services.html : "연구개발팀 서비스" 그룹
│  ├─ 3D프린팅 출력 서비스 자료             →  서비스 카드 1개
│  ├─ 금형 제작 지원 서비스 자료            →  서비스 카드 1개
│  ├─ 디지털 트윈 제작 서비스 자료          →  서비스 카드 1개
│  ├─ 신기술, 신제품 정보(미시적)           →  news.html : "신기술·신제품" 카테고리 기사
│  ├─ 트렌드자료 거시적 자료                →  news.html : "산업 트렌드" 카테고리 기사
│  ├─ 해외출장 자료                         →  news.html : "해외출장" 카테고리 기사
│  └─ 신규업체정보                          →  news.html : "신규업체정보" 카테고리 기사
│
└─ 연구평가팀/                              →  services.html : "연구평가팀 서비스" 그룹
   ├─ KLAB 시그니처 서비스 자료             →  서비스 카드 1개
   ├─ kvillage 브랜드랩 자료                →  서비스 카드 1개
   ├─ 기계 테스트 항목(신발,의류 포함)      →  서비스 카드 1개
   ├─ 사용성 평가 항목 자료                 →  서비스 카드 1개
   ├─ 연구 결과물 해외출장 결과물 보고서    →  서비스 카드 1개
   ├─ 평가 장비 리스트 및 장비 설명         →  서비스 카드 1개
   └─ 필드테스트 항목 자료                  →  서비스 카드 1개
```

핵심 아이디어:

1. **팀 폴더(연구개발팀 / 연구평가팀) = 업무소개 페이지의 그룹 섹션**
2. **팀 폴더 안의 하위 자료 폴더 1개 = 서비스 카드 1개 (또는 기사 카테고리 1개)**
3. **"신기술/트렌드/해외출장/신규업체정보"처럼 시의성 있는 자료 폴더는 업무소개가 아니라 최신정보(뉴스) 쪽으로 분류** — SATRA처럼 "회사 소개"와 "산업 뉴스"를 한 사이트에 같이 두되, 성격이 다른 콘텐츠라 페이지를 분리했습니다.

## 다음 단계 (실제 개발 시 고려할 것)

- 지금은 카드/기사 내용이 폴더명을 참고해 임의로 작성한 예시 텍스트입니다. 실제로는 각 폴더 안의 문서/이미지를 콘텐츠로 연결해야 합니다.
- 실제 서비스는 정적 HTML이 아니라 CMS(콘텐츠 관리 시스템)나 프레임워크(Next.js 등)로 만들어서, 폴더에 자료가 추가될 때 기사가 쉽게 추가/수정되도록 하는 것을 추천합니다.
- 디자인은 회사 로고(`K LAB LOGO.ai`)의 톤에 맞춰 다시 다듬어야 합니다.


## 주간 산업뉴스 운영

글로벌 주요 뉴스와 국내 주요 이슈 10개는 `data/industry-news.json`에서 관리합니다. 최근 7일 발행 기사만 선정합니다. 전체 출처 분류 및 다음 조사 지침은 [주간 뉴스 운영 기준](docs/weekly-news-policy.md)을 참고하세요.

게시 전 `node --test scripts/news-policy.test.cjs`와 `node scripts/validate-news.cjs`로 검증합니다. GitHub Actions에도 동일한 검증을 추가했습니다. 예약 자동 조사 실행은 아직 활성화하지 않았습니다.
